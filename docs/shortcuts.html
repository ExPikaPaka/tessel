Keyboard reference

Every shortcut the program binds, grouped the way the menus are. A shorter version of the same list is inside Tessel under F1, or Help, Keyboard Shortcuts. Combinations that hold Ctrl or Alt work whatever keyboard layout is active: with a Cyrillic layout, the key printed with the Latin letter still triggers the shortcut.

Tools and colours

A tool key works whenever the main window has the focus and you are not typing into a field. Where several tools share a key, pressing it again moves to the next one, and Shift with that key moves back.

On the canvas

Mouse and modifier keys while a tool is in use
InputWhat it does
Right buttonDraws, fills or picks with the secondary colour
Hold Space, or drag with the middle buttonPans the canvas without leaving the current tool
WheelScrolls; with Ctrl it zooms around the pointer
Shift while draggingKeeps a selection square or circular, a shape in proportion, a line or gradient at a fixed angle
Ctrl while dragging a selectionAdds to the selection, whatever the combine mode is set to
Alt while dragging a selectionSubtracts from it
Ctrl+click with the Clone StampSets the source point
Arrow keysNudge the floating pixels under Move Selected Pixels
EnterCommits what the current tool is holding: a moved selection, a line, a curve, a shape
Ctrl+EnterCommits the text being typed
EscCancels it instead
Double click a layer rowOpens Layer Properties
